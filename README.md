# دليل الكلية الذكي

موقع إرشادي عربي RTL لكلية التربية النوعية – جامعة المنوفية – أشمون.

## الملفات
- `index.html`: واجهة الموقع ولوحة المشرف.
- `config.js`: إعدادات Supabase العامة (Publishable key فقط).
- `supabase/schema.sql`: مرجع مخطط قاعدة البيانات والسياسات.

## النشر على Render
- النوع: Static Site
- Build Command: اتركه فارغًا
- Publish Directory: `.`

## الإدارة
سجّل الدخول بحساب Supabase الذي يحمل `app_metadata.role=admin`. يجب تسجيل الخروج ثم الدخول مجددًا بعد تغيير الدور لتحديث الجلسة.

## تنبيه
لا توجد بيانات أماكن فعلية مضافة بعد. أدخل بيانات القاعات والمعامل بعد التحقق منها مع إدارة الكلية. لا تضع أبدًا Secret key أو service_role في ملفات المتصفح.
